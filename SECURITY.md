# Security

To report a security issue, open a GitHub issue that describes the problem without exploit details and asks for a private contact, or contact the maintainer, Aakash Singh Mutum, through the GitHub profile [@AakashMutum](https://github.com/AakashMutum). Please do not publish details until a fix is available.

All data in this repository is synthetic and generated from a seed. It contains no real customer, payment or personal data. The only credentials in the repository are the documented local defaults of Exasol Personal (`sys` / `exasol`), which are for a database bound to localhost. Never point Receipts at a shared database with default credentials.

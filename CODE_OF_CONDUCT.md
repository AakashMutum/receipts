# Code of conduct

Receipts welcomes anyone who wants to use it, report a problem or improve it.

* Be respectful and constructive. Discuss ideas and code, not people.
* No harassment, insults or discriminatory language, in issues, pull requests or anywhere else connected with the project.
* Assume good intent, and ask before assuming.
* Keep reports factual: what you ran, what you expected, what happened.

The maintainer, Aakash Singh Mutum, may edit or remove comments, issues or pull requests that break these points, and may block accounts that keep doing so. To raise a concern, contact the maintainer through the GitHub profile [@AakashMutum](https://github.com/AakashMutum).
